# VLOG Data Logger

VLOG는 콤팩트한 크기의 데이터 수집 및 로깅 장치로, PC가 연결된 상태뿐 아니라 연결되지 않은 상태에서도 동작 가능한 스탠드얼론 데이터 로거입니다.
VLOG는 NC 가공 알루미늄 섀시 구조로 제작되어 차량 테스트 목적으로 사용하기에 충분히 견고합니다. 센서 연결을 쉽게 하기 위해 전면에 센서 커넥터를 배치했으며, 광범위한 전원 옵션을 제공해 차량 전원을 이용해 사용할 수 있습니다.
VLOG 시스템은 견고한 스탠드얼론 차량용 데이터 측정 장치로, 온보드 4채널 아날로그 입력과 4채널 CAN 버스 데이터 측정이 가능합니다.

VLOG는 스탠드얼론 데이터 로거로서, CAN 버스 기반 측정 모듈인 [CSM Minimodule]을 이용해 Thermocouple, Analog, RTD, Strain, Pulse/Counter 등 다양한 신호 측정 채널 확장이 가능합니다. 또한 TCP/IP 통신 기반의 고속 데이터 수집이 가능하며, 광범위한 신호 컨디셔닝 입력 모듈을 지원해 다양한 유형의 입력 신호 측정 기능을 제공합니다.
이 시스템은 실용적인 차량 시험 애플리케이션을 목적으로 고안되었으며, 견고한 구조의 하드웨어로 설계되었습니다. 범용적으로 사용되는 편리한 센서 연결 기능과 ActiveTX 소프트웨어를 함께 사용하면 손쉽게 운용할 수 있는 차량 데이터 측정 장치를 구성할 수 있습니다.

VLOG는 매우 유연하고 컴팩트한 TCP/IP 통신 기반 데이터 측정 장치이며, 동시에 스탠드얼론 데이터 취득 장치로도 사용할 수 있는 데이터 로거입니다. 전용 소프트웨어로 데이터 로깅 기능을 설정할 수 있고, 측정 데이터는 최대 64GB USB 메모리 스틱에 저장할 수 있습니다.
트리거 기반 또는 연속 저장 모두 최대 20 kS/s 속도로 저장 가능하며, 데이터는 USB 메모리 스틱에 파일 형태로 저장됩니다.
본체 데이터 로깅 기능과 PC의 TCP/IP 통신 연결을 통한 ActiveTX 소프트웨어 기반 PC 데이터 저장 기능을 함께 사용해 백업 저장 기능을 구현할 수 있습니다.
USB 메모리 스틱 저장 기능을 수행하면서 동시에 TCP/IP 통신으로 연결된 측정 PC에서 ActiveTX 소프트웨어를 사용해 측정 및 분석 동작을 수행할 수 있습니다.

VLOG는 차동형 입력 신호 처리 기능을 갖추고 있으며, 입력 신호 처리 모듈을 통해 저노이즈, 고정밀 신호를 높은 정확도로 측정할 수 있습니다.
VLOG는 다중 채널 CAN 통신을 통해 ECU 데이터를 수집할 수 있으며, 동시에 아날로그 및 디지털 신호를 동기화해 측정합니다. 이때 모든 측정 데이터는 동기화되어 저장됩니다.
측정된 데이터는 내부 데이터 저장 장치 또는 외부 연결 PC에 동시 저장할 수 있습니다.
VLOG는 기본 데이터 수집 및 분석 목적과 로깅 목적으로 사용할 수 있으며, 차량 거동 데이터 측정 및 다양한 조건의 성능 시험 측정 용도로 활용할 수 있습니다.

PC로 전송되는 데이터는 다양한 유형으로 모니터링할 수 있습니다.
ActiveTX 소프트웨어를 사용해 여러 형태의 화면으로 표시할 수 있으며, 데이터 저장 및 입력 신호 설정과 같은 데이터 수집 기능 등 다양한 옵션을 제공합니다.

![VLOG Connections](/assets/en/product/vlog_connections.webp)

차량 데이터 측정용 VLOG는 다음 목적으로 사용할 수 있습니다.
- 차량 거동 모니터링
- ECU CAN 데이터 모니터링

VLOG는 TCP/IP 통신을 통해 연결된 PC와 함께 작동할 수 있으며, 동시 8채널 16비트 AD 보드를 장착해 채널당 200kHz/ch 샘플링 속도로 아날로그 신호 입력 측정이 가능합니다. 또한 Lemo, BNC, D-SUB 등 범용 커넥터를 제공해 센서를 편리하게 연결할 수 있습니다.

데이터 로깅 기능
스탠드얼론 데이터 로깅은 측정 채널 및 저장 채널 설정, 파일 및 데이터에 대한 별도 저장 동작 설정 등 사용자 설정을 통해 구현할 수 있습니다.

데이터 디스플레이 기능
VLOG는 5인치 LCD 디스플레이 장치(VDU5)를 이용해 VLOG에 수집되는 데이터를 모니터링할 수 있으므로, CAN 데이터 및 아날로그 입력 신호를 모니터링과 동시에 로깅하면서 연결된 PC로 전송할 수 있습니다.
데이터 디스플레이 장치인 VDU5는 차량 CAN 데이터와 센서에 연결된 아날로그 입력 데이터를 모두 표시할 수 있습니다.
VLOG는 100Hz GPS 센서를 옵션으로 장착할 수 있습니다.
VLOG는 일반적으로 주행 중 CAN 데이터 로깅에 사용되며, 필드 센서 데이터 취득에 편리합니다. 또한 트리거 기능을 이용한 차량 데이터 취득/저장과 GPS 데이터를 이용한 차량 경로 데이터 수집 기능을 동시에 제공합니다.
