# APS(Drive) Controller VMS3400

A common method for evaluating vehicle power performance is an acceleration performance test. Traditionally, these tests have been repeated manually by skilled test drivers.

As vehicles continue to deliver higher performance, more diverse and controlled test methods are required for power performance evaluation.

Accurate, quantifiable, and repeatable power performance testing requires a precisely controlled accelerator pedal system.

By replacing manual pedal operation with an accurate and repeatable accelerator pedal controller, power performance tests can be performed with higher precision and consistency.

## APS Connection

For reliable power performance testing, the accelerator pedal must be controlled consistently. The VMS3400 connects directly to the APS circuit and enables precise, repeatable pedal control without relying on driver input.

This approach improves test consistency, reduces operator variability, and supports more objective performance evaluation.

---

## Key Features

The VMS3400 provides vehicle speed control, APS opening control, and RPM control.

- APS opening control supports various combinations of vehicle performance tests.
- Speed control enables control of both vehicle speed and engine RPM.
- Speed control can maintain constant speed and constant acceleration-rate conditions.
- Speed control can run the vehicle automatically according to a pre-stored driving curve.
- By combining the three control functions, the system can replay a wide range of real driving scenarios.
- The VMS3400 includes a built-in 100 Hz GPS and APS controller while minimizing overall device size.
- The VMS3400 is a power performance measurement device with a built-in accelerator pedal controller, so the driver does not need to operate the accelerator pedal.
- The VMS3400 provides a standard APS connector for easy APS sensor connectivity, simplifying test setup and installation.

## Test by APS Control

### Performance Test by APS Control
- The VMS3400 automatically runs test items, measures and stores data during testing, and classifies/manages test results automatically.
- The VMS3400 is an APS-based vehicle performance evaluation device that controls accelerator pedal opening through PC software.
- The VMS3400 automatically controls the accelerator pedal according to programmed modes, enabling precise testing at predefined conditions and timing.
- The VMS3400 reduces the difficulty of maintaining pedal opening manually, minimizes error, and improves repeat-test reproducibility.

### APS Pedal Tip-in/Tip-out Test

When engine RPM reaches the preset value for pedal application, the accelerator pedal is automatically driven to the configured opening, and measurement/evaluation begins.

When engine RPM reaches the preset value for pedal release, the accelerator pedal opening is driven to 0%, and the next test step proceeds.

![Tip-in Tip-out](/assets/en/product/vms3400_tip_in_tip_out.webp)

### Vehicle Starting Acceleration Test

- Acceleration performance evaluation under full-acceleration conditions
- Acceleration performance evaluation under various operating-speed conditions by controlling accelerator pedal input
- Evaluation under fixed APS openings such as 70%, 85%, and 100% full acceleration, including acceleration performance and driving-feel measurement

![Acceleration](/assets/en/product/vms3400_acceleration.webp)

### Vehicle Constant Acceleration & Constant APS Change Rate

- Acceleration test that drives the test vehicle at a target acceleration by controlling vehicle speed with a preset acceleration value

![Speed ramping](/assets/en/product/vms3400_speed_ramping.webp)

### Drive Cycle Function

Test mode for controlling vehicle speed according to preset target speed values.

Because the VMS3400 does not include a brake function for deceleration control, road-test deceleration depends on the vehicle's natural deceleration.

During chassis dynamometer testing, deceleration control is available through the chassis dynamometer brake-assist mode.

![FTP75](/assets/en/product/vms3400_ftp75.webp)

- The Drive Cycle test function allows repeated operation according to a predefined driving mode. It supports driverless operation and consistent repeatability.
- This function can be used on both a chassis dynamometer and a test track. On a chassis dynamometer, the APS controller manages speed in acceleration sections; in deceleration sections, it switches to speed-control mode and sends target speed to the dynamometer to perform braking.
- Drive cycle testing can be executed in unmanned mode on vehicles equipped with automatic transmission or dual-clutch transmission.

### Vehicle Overtaking Acceleration Test

- Measure overtaking acceleration performance under full acceleration or preset accelerator pedal opening conditions
- Measure overtaking acceleration performance at preset pedal openings such as 100%, 80%, and 60%
- Perform acceleration performance tests with preset tip-in/tip-out pedal conditions

![Rolling Start](/assets/en/product/vms3400_rolling_accel.webp)

### Downshift Acceleration Test

- Test that accelerates the vehicle according to a preset accelerator pedal opening curve
- As accelerator pedal opening increases, the transmission downshifts; acceleration performance is evaluated by measuring vehicle response between shift points
