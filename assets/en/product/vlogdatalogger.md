# VLOG Data Logger

VLOG is a compact, standalone data acquisition and logging device that can operate either with a connected PC or independently. It is built with a robust NC-machined aluminum enclosure for in-vehicle testing. Dedicated front connectors allow easy sensor connection, and wide power input options enable operation from vehicle power.

---

The VLOG system is a rugged, standalone in-vehicle measurement device with 8 onboard analog input channels and CAN bus interfaces. It can be used flexibly as a standalone data logger, with channel expansion through CAN bus-based measurement modules and Ethernet-based high-speed data acquisition instruments.
A wide range of signal-conditioning input modules is available to support various input signal types.

The system is designed for practical in-vehicle applications and is built with robust electronic hardware. Popular connector options enable convenient sensor connection, and in combination with ActiveTX software, this provides an easy-to-use in-vehicle measurement solution.

VLOG is a highly flexible and compact Ethernet-based data acquisition system that can be used as a standalone data logger. The logging process is easily configured with dedicated software, and measurement data can be stored on a USB memory stick of up to 64 GB.
For triggered or continuous logging, an aggregate sampling rate of up to 20 kS/s is supported, and data is stored as files on the USB memory stick. The combination of onboard logging and ActiveTX software provides redundancy in data acquisition. With both a USB memory stick and a measurement PC connected via Ethernet, data is logged to the USB stick while ActiveTX on the PC simultaneously measures, analyzes, and stores the same data. Even if the PC connection is lost, measurement data is safely logged to the USB stick.

VLOG is equipped with a differential signal-conditioning module for input signal processing, enabling low-noise, high-precision measurement with high accuracy.
VLOG can acquire ECU data through multi-channel CAN ports while simultaneously measuring analog and digital signals. All data is synchronized, measured, and stored both in internal storage and on a connected external PC.
VLOG can be used for basic data acquisition and logging, as well as advanced analysis tasks, including vehicle behavior measurement and various performance tests under different conditions.

![VLOG Connections](/assets/en/product/vlog_connections.webp)

Data transmitted to the PC can be monitored on various screen types in ActiveTX software, which also provides options for data collection functions such as data storage and input signal settings.

For vehicle data measurement, VLOG can be used for:
- Vehicle behavior measurement and logging
- ECU CAN data monitoring

VLOG operates with a PC connected via Ethernet and is equipped with an 8-channel, 16-bit AD board with simultaneous 100 kHz/ch sampling.
VLOG supports installation of 8-channel analog signal input modules and offers common connector options including Lemo, BNC, and D-SUB for convenient sensor connection.

Data logging capabilities
Standalone data logging is supported through user-defined measurement and storage channels in the configuration file, and separate operation for data storage is also provided.

Data display function
VLOG can be connected to a 5" LCD display unit (VDU5) to monitor current data acquired by VLOG. This enables real-time monitoring and simultaneous logging of both CAN and analog input data, even while connected to a PC and transmitting data to it.
The VDU5 display unit provides vehicle status information from the vehicle CAN port and analog input data from connected sensors.
A 100 Hz GPS sensor can be equipped as an option. VLOG is generally used for CAN data logging while driving and is also convenient for collecting field sensor data with trigger functions and vehicle behavior data with GPS.
