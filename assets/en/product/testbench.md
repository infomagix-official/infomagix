## Automation System Introduction

A typical automation system is applicable to component test benches such as compressors and power steering pumps.
It is a PC-based test automation system that integrates both test bench control and data acquisition,
especially for component bench testing.
The system performs test bench control and interactive data acquisition hardware control.
Real-time measurements and calculated values, such as heat balance and efficiency, are used as judgment parameters.

The automation software supports the following functions:
- Test configuration, screen configuration, and data restore
- Test sequence control, configuration, and restore
- Test Bench Safety & Interlock Control
- PID Control (Motor, Valve, Heater)
- Physical value calculation from test data
- Heat balance and efficiency calculation
- Data replay, file conversion, and report generation
- PID control parameter editing and restore

## Software Function

### Test Bench Control
- Test bench safety and interlock control
- Test sequence creation and editing
- PID control
- Automatic test management

### Configuration
- User-configurable hardware configuration
- Channel-parameterized data manipulation and channel configuration
- User-configurable data logging and storage options
- User-configurable data trigger and storage options
- User-configurable test header information
- End-to-end methods for analog input channel calibration and regression, including multipoint and two-point calibration
- Sensor and transducer linearization

### Operator Interfaces/Displays
- User-configurable screen editing
- Multiple-window screens with configurable screen update rates
- PID control parameter view and configuration
- Test bench monitoring and command control
- Strip chart graph window
- Trigger/alarm operator message and event window
- Alarm window, including alarm configuration and modification during tests
- Online alarm data view window
- Online calibration window
- Online log data view window
- Online digital raw data view window

### Test Data Calculation
- Physical parameter calculation from measured channels
- Heat balance calculation
- Test data validity evaluation

### Data Processing
- Binary data format for compact data structures and high-speed logging
- Log data tree view for easy data file tracing
- Log data header information view
- Text and graph format log data view
- User-configurable trigger/alarm descriptions with automatic links to the data analysis program
- Multiple graph displays
- Graph editing (copy, cut, save as)
- Excel, text, and Access DB file conversion
- Automatic Excel template file conversion
- HTML/Excel/Word report file conversion
- User-selectable multi-format report generator
- EMF graph image export

### Diagnostics
- Analog input, digital input, analog output, and digital output
